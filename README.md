## About me

<img align="right" alt="LUC4N3X workspace" width="340" src="./assets/brand/luc4n3x-workspace.svg" />

Hey, I'm Luca. I like taking rough ideas and turning them into software I can actually use.

Most days I bounce between **Android apps, backend services, tooling and infrastructure**. I enjoy the part after something starts working: finding what still feels off, fixing the weird edge cases and making the whole thing cleaner.

- I work mostly with **Kotlin, Jetpack Compose, Python, Node.js, Linux and Docker**
- I like bugs that only show up on one device, one network or one very specific path
- I prefer a focused fix I understand well over a rewrite just because the diff looks impressive
- **Levyra** is where a lot of my Android and product ideas end up
- If it involves **Android, self-hosting, APIs, performance or useful tools**, I'm probably interested

[![Stars](https://img.shields.io/github/stars/LUC4N3X/Levyra-deepsound?style=for-the-badge&logo=github&color=38BDF8&logoColor=white&labelColor=07111F)](https://github.com/LUC4N3X/Levyra-deepsound/stargazers)
[![Latest Release](https://img.shields.io/github/v/release/LUC4N3X/Levyra-deepsound?style=for-the-badge&logo=android&color=22D3EE&logoColor=white&labelColor=07111F)](https://github.com/LUC4N3X/Levyra-deepsound/releases/latest)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-A78BFA?style=for-the-badge&logo=gnu&logoColor=white&labelColor=07111F)](https://github.com/LUC4N3X/Levyra-deepsound/blob/main/LICENSE)
[![Live Website](https://img.shields.io/badge/Website-levyra.dpdns.org-818CF8?style=for-the-badge&logo=firefox&logoColor=white&labelColor=07111F)](https://levyra.dpdns.org)

</div>

> **Levyra** is a modern open-source music player engineered for Android and Windows. Built without shortcuts: native AndroidX Media3 playback engine, offline-first download resilience, time-synchronized lyrics, and a responsive Jetpack Compose interface.

<table width="100%">
  <tr>
    <td width="50%" valign="top">
      <h4>⚡ Playback & Audio Engine</h4>
      <p>Low-latency AndroidX Media3 / ExoPlayer pipeline, custom audio session management, gapless playback, and resilient queue restoration.</p>
      <code>Kotlin</code> · <code>Media3</code> · <code>ExoPlayer</code> · <code>Coroutines</code>
    </td>
    <td width="50%" valign="top">
      <h4>📦 Offline-First & Downloads</h4>
      <p>Resumable background downloads, local cache hierarchy, duplicate prevention, audio tag embedding, and storage integrity checks.</p>
      <code>Room DB</code> · <code>WorkManager</code> · <code>Cache Architecture</code>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h4>🎙️ Synced Lyrics & Discovery</h4>
      <p>Real-time scrolling synchronized lyrics, multi-provider resolution scoring, rich metadata enrichment, and ambient discovery algorithms.</p>
      <code>REST APIs</code> · <code>LevyraExtractor</code> · <code>Lyrics Engine</code>
    </td>
    <td width="50%" valign="top">
      <h4>🎨 Native Fluid Experience</h4>
      <p>Pure Jetpack Compose UI with Material You dynamic color adaptation, smooth canvas gestures, desktop layout support, and refined micro-interactions.</p>
      <code>Jetpack Compose</code> · <code>Material 3</code> · <code>Desktop Compose</code>
    </td>
  </tr>
</table>

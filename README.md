## About

I'm an independent developer from Italy, working primarily on Android applications, cross-platform software and backend APIs. My main project is [Levyra](https://github.com/LUC4N3X/Levyra-deepsound), where I focus on music playback, performance, user experience and long-term maintenance.

I'm also interested in self-hosted software, media extraction and open-source infrastructure.

## Featured project

**[Levyra](https://github.com/LUC4N3X/Levyra-deepsound)** — An open-source music player for Android and Windows, with music discovery, synced lyrics and local playback.

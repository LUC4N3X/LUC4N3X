## About

<img align="right" alt="LUC4N3X workspace" width="340" src="./assets/brand/luc4n3x-about.webp" />

I'm LUC4N3X, based in Italy.

Most of my time goes into [Levyra](https://github.com/LUC4N3X/Levyra-deepsound), an open-source music player for Android, Windows and Linux. Alongside that, I work on media extraction, Linux backend services, and [antigravity-thalarch](https://github.com/LUC4N3X/antigravity-thalarch).

I test playback on real mid-range phones and keep user data local. If something breaks in one of my repos, open an issue.

It keeps streamed tracks and local audio files in one library, saves offline downloads as plain audio files, and pulls synced lyrics from LRCLIB. It needs no account and has no ads or telemetry.

Android runs on Kotlin, Jetpack Compose and AndroidX Media3; Windows and Linux builds use Compose Multiplatform and libVLC.

## Stack

<img align="right" alt="Linux workstation" width="340" src="./assets/brand/luc4n3x-linux-stack.webp" />

Daily driver is Linux.

- Android & desktop: `Kotlin`, `Jetpack Compose`, `Compose Multiplatform`, `Media3`, `libVLC`
- Backend & tooling: `Python`, `FastAPI`, `AsyncIO`, `Node.js`, `TypeScript`
- Data & infra: `SQLite`, `Room`, `Redis`, `Docker`, `Cloudflare`, `GitHub Actions`

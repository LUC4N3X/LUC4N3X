## About

I'm Luca. Most of my projects start because I want something to exist, use it for real, and eventually find the edge cases the first version did not account for.

The part I enjoy most is when software works **almost** perfectly: playback that behaves differently on one device, an upstream service that changes without warning, a UI that is technically correct but still feels wrong, or a fix that looks obvious until the evidence says otherwise.

I prefer understanding the failure, making the smallest useful change and verifying the result over hiding the problem behind a rewrite.
